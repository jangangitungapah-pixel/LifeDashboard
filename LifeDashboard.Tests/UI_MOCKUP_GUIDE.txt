## Interactive States

### Buttons
```
Default:  Transparent bg, colored border, colored text
Hover:    Slightly darker border
Pressed:  Filled with color
Disabled: Grayed out
```

### Cards
```
Default:  Normal shadow
Hover:    Slightly elevated shadow
Tap:      Scale 0.98
```

### Progress Bars
```
Animation: Smooth cubic easing (400ms)
Colors:   Cyan (XP), Purple (Tasks), Pink (Habits)
Height:   8px (main), 4px (cards), 6px (heatmap)
```
