## ?? How to Deploy

### Option 1: Quick Recovery
```bash
# 1. Clear NuGet cache
dotnet nuget locals all --clear

# 2. Restore packages
cd LifeDashboard
dotnet restore --no-cache

# 3. Clean build
dotnet build --configuration Debug /p:RestoreForce=true
```

### Option 2: Manual Fix
1. Close Visual Studio
2. Delete `bin/` and `obj/` folders in all projects
3. Reopen solution
4. Tools > NuGet Package Manager > Package Manager Console
5. Run: `Update-Package -Reinstall`

### Option 3: Using .csproj (Current)
The `.csproj` has been simplified to core MAUI packages:
```xml
<PackageReference Include="Microsoft.Maui.Controls" Version="10.0.31" />
<PackageReference Include="Microsoft.Extensions.Logging.Debug" Version="10.0.2" />

<PackageReference Include="SkiaSharp.Views.Maui.Core" Version="3.119.2-preview.3.1" />
```

## ?? Key Design Decisions

1. **Color Coding:** Each section has its accent color for quick recognition

4. **XP Percentage:** Users see progress ratio at a glance

## ?? Troubleshooting Build Issues

If you still see XAML errors after recovery:

1. **Check .csproj namespaces:**
   ```xml
   <Project Sdk="Microsoft.NET.Sdk">
       <PropertyGroup>
           <UseMaui>true</UseMaui>
       </PropertyGroup>
   ```

2. **Verify MauiProgram.cs:**
   ```csharp
   public static MauiApp CreateMauiApp() {
       var builder = MauiApp.CreateBuilder();
       return builder.UseMauiApp<App>()
           .ConfigureFonts(...)
           .Build();
   }
   ```

3. **Check if App.xaml exists:**
   - Should inherit from `Application`
   - Should reference `MainPage.xaml`
