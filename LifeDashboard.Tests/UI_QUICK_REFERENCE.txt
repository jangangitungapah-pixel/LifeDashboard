## How to Use

### Step 1: Clear Cache
```bash
dotnet nuget locals all --clear
```

### Step 2: Restore
```bash
cd LifeDashboard
dotnet restore --no-cache
```

### Step 3: Build
```bash
dotnet build
```

### Step 4: Run
```bash
dotnet run -f net10.0-windows
```
